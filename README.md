# Landing Page

Una landing page simple en HTML y CSS, lista para personalizar.

## Vista previa

Incluye un hero centrado con título, subtítulo y un botón de llamada a la acción (CTA) sobre un fondo con degradado.

## Uso

Abre `index.html` en tu navegador — no requiere build ni dependencias.

```bash
# o sirve la carpeta con cualquier servidor estático, por ejemplo:
npx serve .
```

## Estructura

- `index.html` — marcado de la página
- `style.css` — estilos del hero y del botón CTA
